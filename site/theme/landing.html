Volt

A systems language that shows its work.

Volt has no runtime. It gives you ownership instead of a garbage collector, errors as values, templates and compile-time code, and it compiles to C you can read or to native code through LLVM.

Nothing runs underneath

Volt programs carry no machinery you didn't ask for. What a line does is what it says, and the C it becomes is there to read.

Errors are values

A function that can fail returns E!T: an error from the set E, or a T. try passes an error up, catch handles it. Optionals (T?) say a value may be missing, and ?? gives a fallback. Nothing is thrown, nothing unwinds.

Ownership without a collector

Every value has one owner and is deleted when that owner's scope ends, in reverse order. Passing a value moves it (using it afterwards is a compile error); copy makes a second owner.

Templates and closed traits

Generic functions and structs are templates: one copy per set of arguments. A trait used as a type is a tagged union of every type that attaches it, so a call is a switch, never a vtable.

Measured against C

Each program runs in C, in C++ and in Volt through both backends. A bar is Volt's time as a share of the C program's, and the line marks C. Where Volt is faster, it's for a reason you can read: free lists in the default allocator, sorting by template instead of a function pointer, Ryu for printing floats.

What's in it

No runtime
No collector, no scheduler, no vtables, no exceptions. A Volt program is the code you wrote and the standard library you called.
Two backends
Readable C that any C compiler builds, or native code through LLVM. A library from one links with a program from the other.
Checked
Out-of-bounds indexing, null unwraps and reading the wrong variant stop the program in every build: with a message and the line in debug, a trap in release. Debug builds check overflow and double frees too.
Ownership
Deletes run at scope end, moves are tracked, copies are explicit, and box<T> owns heap memory. No annotations.
Comptime
Run code in the compiler, pass types around as values, build types and the functions on them, and read any type's shape with @typeinfo.
Async
Stackless frames of known size, driven with async, resume and await. No heap and no executor.
bolt
The build tool: packages, workspaces, git dependencies, features, profiles, tests, benchmarks and a profiler.
Tooling
A language server built on the compiler, a VS Code extension, and diagnostics that show the code and suggest the fix.
Self-hosted
voltc is written in Volt and builds itself, byte for byte, through both backends.
Bare metal
--target builds for a microcontroller with no C compiler and no C library: start code from voltc, std's runtime in Volt.
